## The package itself

```bash npm2yarn
npm install daterly
```

## Peer dependencies

```text
react >= 17.0.0
react-hook-form >= 7.0.0  # optional, only if you use /rhf
```

If you don't need the RHF wrappers, installing `react-hook-form` is not required.

## Adding the styles

Styles load automatically when you import components from `daterly` or `daterly/rhf`:

```tsx
import { DatePicker } from 'daterly'
```

The package includes the base CSS variables and `react-day-picker` styles. A separate `import 'daterly/styles'` is no longer needed; the previous import remains available for compatibility. Your app's bundler must support CSS imports.

## What gets exported

| Entry point | What's inside |
|-------------|------------|
| `daterly` | `DatePicker`, `DateRangePicker`, `Calendar`, types `DateRange`, `DatePickerProps` |
| `daterly/rhf` | `RHFDatePicker`, `RHFDateRangePicker` |
| `daterly/styles` | Base CSS variables and calendar styles |

## TypeScript

Types ship with the package — no separate `@types/*` needed. Every component exports its `*Props` interfaces.
